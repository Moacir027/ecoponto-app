# ♻️ Ecoponto Uberlândia
App web para celular que mostra os ecopontos de Uberlândia (MG) no mapa, encontra o mais próximo e traça rota.
## Publicar no GitHub Pages
1. Crie um repositório e envie estes arquivos.
2. Settings → Pages → Branch `main` → Save.
Envie também os 4 arquivos .png de ícone e o arquivo `sw.js`.
## Instalar como app (PWA)
Abra o site no Chrome do Android → menu ⋮ → **Instalar app** (ou **Adicionar à tela inicial**). No iPhone: Safari → Compartilhar → **Adicionar à Tela de Início**.
## Atualizar o app
Depois de mudar qualquer arquivo, altere `VERSION` em `sw.js` (ex.: `ecoponto-v2`) para os usuários receberem a nova versão.
## Editar ecopontos
Altere `data.js`. As coordenadas atuais são aproximadas.
